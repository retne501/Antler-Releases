# Antler · 鹿角蕨收藏庫

Antler 是獨立開發的 Android 收藏庫，可儲存網址與圖片，使用收藏夾、標籤、搜尋與專注模式整理內容。

此儲存庫只作為 **Antler 官方 APK 發佈及 App 內更新來源**，開發中的測試版本不等於正式版。

## 下載與更新

正式版本通過完整驗收後，將放在 [GitHub Releases](https://github.com/retne501/Antler-Releases/releases)。每個正式 Release 需同時提供已簽章 `.apk` 及 `antler-update.json`（套件名稱、versionCode、APK SHA-256、版本資訊）。App 驗證檔案及簽章後才交由 Android 安裝程式讓使用者確認。

- **正式套件名稱：** `com.retne501.antler`
- **作者／發佈帳號：** `retne501`
- **Android：** 10 以上
- **目前：** 尚未對外正式發佈，請勿下載未驗證的第三方 APK。

Antler 與官方 Tuckii 無關，也不代表提供官方付費權益。雲端同步需要使用者自行授權；不會公開雲端收藏或 Google OAuth token。
